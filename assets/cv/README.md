# CV

`Marlon_Steiner_CV.pdf` is what the **Download CV** button in the panel serves.

It is generated by [`scripts/mkcv.py`](../../scripts/mkcv.py) from the same
content as the HTML panel, deliberately **without the phone number**, so the
public file and the public page say the same thing.

Regenerate after editing that script:

```bash
python3 scripts/mkcv.py
```

Nothing reads the file's contents, so you can also just drop your own designed
PDF here under the same name and delete the script. If you rename it, update the
`href` in `index.html`.
